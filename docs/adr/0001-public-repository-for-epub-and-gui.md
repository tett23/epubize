# ADR 0001: EPUB の生成と管理 GUI を、取得とは別の公開リポジトリとして MIT ライセンスで作る

ステータス: 採択

## 文脈

Web 小説を取得し、EPUB にして読みたい。
取得（クロール）は対象サイトごとの事情に強く依存するため、非公開のリポジトリで扱っている。
一方、取得済みのデータから EPUB を生成する部分と、作品を管理する GUI は、サイトに依存せず公開して問題ない。
以前は `kindize` という名前で同様のことをしていたが、継承はしない。

## 実装すること

- EPUB の生成と管理 GUI を、このリポジトリ `epubize` で作る
- リポジトリは公開とし、ライセンスは MIT とする
- 取得（クロール）は扱わない。取得側とのデータの受け渡し方法は、設計を始めるときに新たな ADR で決める

## 実装しないこと

- Web 小説の取得、対象サイトごとの解析は実装しない
- 著作物（Web 小説の本文など）をリポジトリに含めない
- `kindize` のコードや設計は引き継がない

## テスト設計

- 方針の決定であり、コードを伴わないため、テストはない
- 今後のテストのフィクスチャは、著作物を含まない合成データで作る

## トレードオフ

- 取得と生成が別のリポジトリに分かれるため、両者の間のデータ形式を別途決めて保つ必要がある
- 公開リポジトリでは、取得側の事情（対象サイトの構造など）を前提にした実装を置きにくい
