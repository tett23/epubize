# ADR 0020: 管理画面で、クローラーの実行ファイル、定期取得、購読の解除を扱い、設定を settings.json に持つ

ステータス: 採択

## 文脈

クローラーの実行ファイルは、設定画面を作るまでの仮の方法として、PATH などから探していた（ADR 0018）。
定期取得は、毎日 3:00 に決め打ちしていた（ADR 0019）。どちらも、管理画面で設定できるようにすると決めていた。
購読を外す方法がなく、取得できなくなった作品を外すには `novels.json` を手で直す必要があった（ADR 0014）。

## 実装すること

- 画面に `settings` のページを足し、見出しの横からたどれるようにする
- 管理画面で扱うものは次のとおりとする
  - クローラーの実行ファイル。空欄なら、これまでどおり自動で探す（ADR 0018）。いま使っているものと、自動で見つかるものを表示する
  - 定期取得を行うかと、その時刻（ADR 0019）
  - 購読の一覧と、購読を外すボタン。外す前に確かめる
  - 環境と、購読の一覧、設定、データベースの置き場所。読むだけとする
- 設定は `~/.config/epubize/<環境>/settings.json` に持つ。購読の一覧（ADR 0014）と同じディレクトリに置き、手でも直せるようにする
  - ファイルがなければ既定値（クローラーは自動で探す、定期取得は毎日 3:00）を使う
  - 知らない項目は無視し、ない項目は既定値で埋める
  - 保存する前に値を確かめる。時刻が `HH:MM` でない、クローラーの実行ファイルがない、または実行できないときは、保存しない
  - 書き換える前に `settings.json.bak` を作り、一時ファイルに書いてから置き換える
  - ファイルが壊れていても起動できるよう、読めなければ既定値で動かし、理由を管理画面に出す
- 保存した設定は、再起動せずにすぐ反映する
  - クローラーを差し替える。積んであるタスクは、取り出されたときに新しいクローラーで取得する（ADR 0015）
  - 定期取得は、壁時計を見るたびに設定を読み直す。無効の間は行わない
- クローラーが見つからないときも取得のキューは作り、取得は「クローラーがない」という失敗にする。管理画面で指定した後に使えるようにするため
- 購読を外すときは、書き換える前に `novels.json.bak` を作る（ADR 0014 と同じ）。取得済みの作品のデータは消さない
- これにより、ADR 0018 のクローラーの探し方（設定を見ない）と、ADR 0019 の決め打ちの時刻を改める。ADR 0018 と ADR 0019 は、そのほかの決定が生きているため、ステータスを採択のまま残す

## 実装しないこと

- クロールの間隔は設定できるようにしない（ADR 0015）
- Kindle への送信の設定（メールアドレス、SMTP）は扱わない。送信を実装するときに、パスワードの持ち方とあわせて決める
- 設定をデータベースに持つことはしない。データではなく、手で直すこともある設定のため
- 購読を外したときに、取得済みの作品のデータを消すことはしない。消すときは作品のページの remove episodes を使う

## テスト設計

- `src-tauri/src/settings.rs`：ファイルがなければ既定値であること、ない項目を既定値で埋め、知らない項目を無視すること、保存すると前の内容が `.bak` に残り一時ファイルが残らないこと、正しくない時刻やクローラーでは保存せずファイルが変わらないこと、壊れたファイルを拒むこと
- `src-tauri/src/subscriptions.rs`：購読を外すと前の内容が `.bak` に残り、ほかのキーが残ること、数値で持つ hameln の ID も外せること、購読していなければ書き換えず `.bak` も作らないこと
- `src-tauri/src/fetch/mod.rs`：クローラーがなければ取得が失敗し、差し替えた後は新しいクローラーで取得すること
- `src-tauri/src/schedule.rs`：無効の間は時刻を越えても行わず、有効にして時刻を変えると新しい時刻で行うこと
- debug ビルドの `.app` で、管理画面の表示、設定の保存と反映、正しくない値の拒否、購読を外すことを確かめる

## トレードオフ

- 設定を JSON のファイルに持つため、画面とファイルの両方から変えられる。ファイルを手で直した後は、アプリを起動し直すまで反映されない
- クローラーを差し替えても、実行中の取得は前のクローラーで最後まで動く
- 購読を外しても作品のデータが残るため、作品の一覧には残り続ける
